# R Markdown

This skill covers the structure of an R Markdown report, whatever its subject. The rules for the R code inside the chunks are in the `r` skill. This skill gives only what is specific to a report. Content that belongs to one client, such as branding, is in that client's own report skill. It has one reference file:

- `references/coding.md` — read this when writing, editing, or reviewing any R Markdown report. It covers:
    - YAML front matter and params
    - chunk conventions
    - helper functions
    - error handling in a report
    - markdown and HTML conventions

This file assumes the global standing instructions (`~/.claude/CLAUDE.md`) are already in effect: interaction style and documentation/writing standards live there.
