# Inventory and discography

Step 2 of `SKILL.md`: list what is on disk, then compare it with a discography.

## 1. Inventory

- List every folder and file, recursively, with sizes. Note the format (FLAC, MP3, other), disc folders, rip logs (`.log`), CUE sheets (`.cue`), scans, and any single-file-plus-CUE album.

- Read enough of each album to identify the release: folder name, rip log (the log names the CD and often the catalog number), CUE `TITLE`/`PERFORMER`/`CATALOG` lines, track count, and track lengths.

- Flag duplicates: two folders holding the same album (different rips, a remaster, a reissue with bonus tracks, a foreign edition).

- Flag folders that hold more than one album (an entire discography, a 2-on-1, a box set) and folders that hold part of an album.

## 2. Discography

- Wikipedia is a starting point, not the source of truth. Ditto for files on disk. An album on disk that Wikipedia does not list is not wrong, it needs checking. Use Discogs, AllMusic, label catalogs, and genre-specific discographies to determine if an album is an official release.

- For each album, find: the billed artist, whether it is a studio, live, or compilation release, and the year of first release.

- List the artist's Studio, Live, and Compilation releases that are missing from the folder.
