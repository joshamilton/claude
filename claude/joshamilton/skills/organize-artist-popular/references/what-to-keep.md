# What to keep, and the Delete folder

Step 3 of `SKILL.md`: which copy of each album stays, and what goes to Delete.

## 1. What to keep

- One copy per album. Keep the copy closest to the original release: no bonus tracks, not a remaster, the earlier release.

- Exception: when an album was released in editions with different numbers of discs (for example a 1-disc and a 2-disc edition), keep one copy of each edition. Folder names are in `references/folder-layout.md`.

- Region: prefer a US or European edition over one from anywhere else, where one is on disk. An edition from elsewhere is kept only when it is the only copy.

- Same master, two rips: when a track-by-track rip and a single-file rip hold the same master (same year and catalog), keep the track-by-track rip. The same holds for an image rip that was later split into tracks: when two rips share the same table of contents, keep the one ripped track by track with AccurateRip results, and flag any track AccurateRip could not confirm.

- Compilations (greatest hits, best-of, live hits, outtake collections, and collections of an artist's singles) are kept, in `Compilation`.

    - A compilation draws its tracks from other sources, so the one-copy rule does not compare it with the albums, even when every track is also on an album.

    - The one-copy rule still applies between editions of the same compilation, except that editions with different numbers of discs are each kept (the exception above).

- Repackaged albums are not compilations: a 2-on-1 set or a box set of complete albums only puts whole albums in a new package. Split out any album that is not on disk separately, then move the set to Delete.

## 2. What not to keep

- Unofficial releases: bootleg concerts and radio broadcasts (releases marked "Unofficial Release" on Discogs) go to Delete. An unofficial CD of an official album that was never issued on CD is the only source of that album, so it is kept under the one-copy rule.

- Singles and EPs: the user does not acquire them.

## 3. The Delete folder

- The Delete folder goes inside the artist folder: `Processing/<Artist>/Delete/`. It is not a shared folder in Processing.

- Rejected albums keep their original folder names, so the user can tell what each one was.

- Parent folders emptied by moves go into Delete too.
